# Lumen Worship — downloads

Church presentation software for Windows that works offline: songs, scripture, slides and media on the congregation screen, the stage monitor and your phone.

**Free for 30 days — everything unlocked. No card, no sign-up, no payment.**

## Download

Get the newest installer from the **[Releases](../../releases/latest)** page (`Lumen-Worship-Setup.exe`), or from the website: **https://lumen.pippulsepro.com**

Windows 10 and 11, 64-bit.

Windows may show a "Windows protected your PC" screen the first time because the installer is not digitally signed yet. Click **More info → Run anyway**.
